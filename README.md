# نظام تسجيل الحضور والغياب الإلكتروني 🏫
### مدرسة ذكور مدينة إربد الإعدادية الثانية (مدرسة الخطيب - فوعرا)
**وكالة الأمم المتحدة لإغاثة وتشغيل اللاجئين الفلسطينيين في الشرق الأدنى (UNRWA)**  
**دائرة التربية والتعليم - الأردن | رمز المدرسة: 10000596**  
**مدير المدرسة: الأستاذ لؤي تيسير نمر الخطيب**

---

## 📌 نبذة عن المشروع
منظومة إلكترونية متكاملة وسحابية لتسجيل ومتابعة حضور وغياب المعلمين والكوادر الإدارية في المدرسة، مبنية بأحدث تقنيات الويب (React 19 + TypeScript + Tailwind CSS + Node.js/Express) مع ميزة التحقق من التواجد الجغرافي (Geofencing) في حرم المدرسة في منطقة فوعرا - إربد، ومزامنة لحظية عبر السحابة مع إشعارات فورية لهاتف المدير.

---

## ✨ المميزات الرئيسية
1. **الترويسة الرسمية المعتمدة**: مدرسة ذكور مدينة اربد الاعدادية الثانية، مدير المدرسة لؤي الخطيب، وكالة الغوث الدولية (UNRWA).
2. **بوابة دخول مزدوجة**:
   - دخول المدير بكلمة سر قابلة للتعديل.
   - دخول المعلمين بالرقم الوظيفي (31 معلماً مدرجين مسبقاً من سجلات الوكالة) وكلمة السر 12345.
3. **خيارات الحضور والغياب الأربعة**:
   - حاضر (دوام كامل).
   - طارئة (إجازة عرضية مع الرصيد).
   - مرضية (عذر أو تقرير طبي).
   - مغادرة (إذن مغادرة رسمي أثناء الدوام مع تحديد التوقيت).
4. **التحقق من الموقع الجغرافي (Geofencing)**:
   - منع التسجيل إلا عند التواجد داخل حرم مدرسة الخطيب - فوعرا.
   - إمكانية تفعيل أو تعطيل النطاق الجغرافي من قِبل المدير وتعديل الإحداثيات ونصف القطر.
5. **لوحة تحكم وتقارير متقدمة للمدير**:
   - تسجيل الحضور الفردي أو الجماعي بنقرة واحدة لكافة المعلمين المتبقين.
   - تقارير: يومية، أسبوعية، شهرية (30 يوماً)، سنوية (2026-2027)، تقرير مفرد لكل معلم، وتقرير جماعي مطابق لكشف أحوال الموظفين (EMIS).
   - تصدير التقارير إلى Excel (CSV) والطباعة الرسمية.
6. **إدارة كادر المدرسة (CRUD)**:
   - إضافة، تعديل، حذف، وتغيير أرقام وأسماء المعلمين وتخصصاتهم.
7. **إشعارات الهاتف الفورية والتخزين السحابي**:
   - تخزين سحابي فوري عبر السيرفر.
   - تنبيهات فورية لهاتف المدير مع نغمة صوتية وإشعار متصفح عند تسجيل أي معلم.
   - إمكانية إرسال تقرير الحضور اليومي للمدير عبر واتساب بنقرة واحدة.

## 🚀 طريقة التثبيت والتشغيل على جهازك المحلي (Localhost)

### 1. المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
- تثبيت Git.

### 2. تنزيل المشروع وتثبيت الحزم
```bash
# 1. الدخول لمجلد المشروع
cd school-attendance-system

# 2. تثبيت الحزم والمكتبات
npm install

# 3. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على الرابط:
`http://localhost:3000`
